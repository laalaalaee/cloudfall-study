Cloudfall Study is a free website where students find notes, previous year question papers, lab files, assignments and syllabus PDFs for their university, organised by school, semester and subject. It holds more than 15,000 files covering Amity University Noida, Amity University Gurugram, NIT Delhi and the GATE exam. Reading requires no account and no payment.

This repository is an index of the website. It contains no files, only links to the relevant pages.
